# Seoul Bar Tour — SANS Field Notes

https://jslee1019.github.io/seoul-bar-tour/

A mobile-friendly, standalone HTML guide to 18 Seoul bars across six neighborhoods, based on barhopping_girl public posts. Independent guide, not an official account website.

- Weekday filters and suggested visiting times.
- Google Maps, Naver Map and Instagram links.
- Visit checks and notes saved only to this browser with localStorage; no cross-device sync.
- Hours checked 2026-10-06 from Google Maps, Brown Study from Tabling; not live availability. ASASI cocktail service hours need confirmation.

GitHub Pages deploys index.html from main / root. No build step or third-party scripts.
